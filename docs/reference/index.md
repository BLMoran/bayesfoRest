# Package index

## Main Functions

Core functions for creating Bayesian forest plots

- [`bayes_forest()`](https://blmoran.github.io/bayesfoRest/reference/bayes_forest.md)
  : Create Bayesian Forest Plot for Meta-Analysis
- [`rob_plot()`](https://blmoran.github.io/bayesfoRest/reference/rob_plot.md)
  : Create Risk of Bias Plot
- [`rob_summary()`](https://blmoran.github.io/bayesfoRest/reference/rob_summary.md)
  : Create a Weighted Risk of Bias Summary Plot
- [`overall_plot()`](https://blmoran.github.io/bayesfoRest/reference/overall_plot.md)
  : Create posterior plots for Bayesian meta-analysis
- [`funnel_plot()`](https://blmoran.github.io/bayesfoRest/reference/funnel_plot.md)
  : Funnel Plot (multi-backend)
- [`sensitivity_plot()`](https://blmoran.github.io/bayesfoRest/reference/sensitivity_plot.md)
  : Generate Sensitivity Analysis Plot for Bayesian Meta-Analysis
- [`ecdf_prior_plot()`](https://blmoran.github.io/bayesfoRest/reference/ecdf_prior_plot.md)
  : ECDF Plot Comparing Priors (fixed section)
- [`ecdf_model_plot()`](https://blmoran.github.io/bayesfoRest/reference/ecdf_model_plot.md)
  : ECDF Plot Comparing Model Strategies (fixed prior)

## Example Datasets

Example data for binary and continuous outcomes
