# Package index

## Main Functions

Core functions for creating Bayesian forest plots

- [`bayes_forest()`](https://blmoran.github.io/bayesfoRest/reference/bayes_forest.md)
  : Create Bayesian Forest Plot for Meta-Analysis
- [`rob_plot()`](https://blmoran.github.io/bayesfoRest/reference/rob_plot.md)
  : Create Risk of Bias Plot
- [`rob_overall()`](https://blmoran.github.io/bayesfoRest/reference/rob_overall.md)
  : Derive an overall risk of bias judgement
- [`overall_plot()`](https://blmoran.github.io/bayesfoRest/reference/overall_plot.md)
  : Create posterior plots for Bayesian meta-analysis
- [`funnel_plot()`](https://blmoran.github.io/bayesfoRest/reference/funnel_plot.md)
  : Funnel Plot (multi-backend)

## Example Datasets

Example data for binary and continuous outcomes

- [`binary_outcome`](https://blmoran.github.io/bayesfoRest/reference/binary_outcome.md)
  : Studies Comparing Medications on Post-Operative Nausea and Vomiting
- [`cont_outcome`](https://blmoran.github.io/bayesfoRest/reference/cont_outcome.md)
  : Studies Comparing Truncal Blocks on Pain Outcomes
