# bayesfoRest: Forest Plots for Bayesian Meta Analyses in R

bayesfoRest creates forest plots for Bayesian meta-analyses using
various modelling backends including brms, MetaStan, bayesmeta,
rstanarm, rstan, cmdstanr, and R2jags. Supports both common-effects and
random-effects models with customizable visualization options.
